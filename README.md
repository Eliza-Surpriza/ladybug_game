# ladybug_game

The Ladybug Game is a board game made for young children. I played it a lot as a kid and enjoyed seeing the cute ladybug characters like "Olivia Orange" and "Tommy Teal" progress along the path towards the rose garden, eating aphids and avoiding the praying mantis on their way.

One day while visiting my family during college, we decided to play the Ladybug Game for some fun nostalgia. It brought back some delightful childhood memories as well as a fascination about the game mechanics. I was curious to see how the game would work as a text-based adventure in code, so I took note of each of the cards and the spaces on the board game, eager to begin coding.

My code fully incorporates all the rules of the Ladybug Game and even adds some extra features, such as letting you pick names for your ladybug avatar beyond the main four presented in the original game.
